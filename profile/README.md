# python-e18e

We help Python projects adopt modern tooling and better dependencies through small, verifiable upstream contributions. Inspired by [e18e](https://e18e.dev/).

Start with the [ecosystem issue tracker](https://github.com/python-e18e/ecosystem-issues), browse [package replacements](https://github.com/python-e18e/module-replacements), or inspect a project with the [CLI](https://github.com/python-e18e/cli). The [initiative repository](https://github.com/python-e18e/python-e18e) explains the roadmap and contribution process.
